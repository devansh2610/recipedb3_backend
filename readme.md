## Setup & Testing
To test the APIs locally using SwaggerUI:
1. Install dependencies: `npm install`
2. Start the server: `npm start`
3. Navigate to http://localhost:3000/api/docs/ in your browser.

Alternatively, to test the APIs locally using Postman:
Import the `RecipeDB3_Postman_Collection.json` file (included in this repo) into Postman.
